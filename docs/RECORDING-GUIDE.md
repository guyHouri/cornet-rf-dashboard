# הקלטה עצמאית ל־24 שעות

המטרה: ה־Cornet מודד ושומר לבדו, ללא מחשב מחובר כל הלילה. המחשב משמש רק בסוף לצורך ייצוא.

שמות התפריטים משתנים מעט בין ED88TPlus, ED98QPro5G וגרסאות קושחה. חפש את המקבילות `Logger Setup`, `Logg time`, `Clear buffer`, `Save config`, `Save to FlashMem`, `Read from FlashMem`, `Data2Send` ו־`Send data`.

## לפני שמתחילים

1. אם יש מדידות קודמות שחשובות לך, ייצא אותן קודם. `Clear buffer` מוחק את הבאפר הפעיל.
2. כוון את השעון שלך ורשום את שעת ההתחלה המתוכננת. הייצוא אינו כולל שעה מוחלטת לכל דגימה.
3. ודא שמקור המתח יספיק לכל 24 השעות.
4. מקם את המכשיר לפני תחילת הסשן. שמור על כיוון ומיקום קבועים ותעד אותם.

## הכנת סשן חדש

1. היכנס ל־`Logger Setup` במכשיר.
2. קבע `Logg time = 2 min`.
   - 24 שעות / 2 דקות = 720 נקודות.
   - ב־ED98QPro5G, זיכרון של 1,024 נקודות מכסה 34 שעות ו־8 דקות.
   - בדגמי ED88TPlus ישנים עם 1,000 נקודות, הכיסוי הוא 33 שעות ו־20 דקות.
   - אם אין במכשיר 2 דקות, בחר 3 דקות; היצרן מציין כיסוי של עד 50 שעות.
3. בחר `Clear buffer` **רק עכשיו**, לפני המדידה החדשה.
4. בחר `Save` או `Save config` כדי לשמור את ההגדרה.
5. צא מ־Logger Setup.
6. ודא שהמכשיר אינו במצב `HOLD`. HOLD משהה את ההקלטה ולכן הוא לא אמור להישאר פעיל במשך הלילה.
7. נתק את המחשב והתחל את הסשן.
8. רשום מיד את שעת ההתחלה בפועל בקובץ המטא־דאטה או בנייר.

ה־Cornet שומר בכל חלון את הקריאה המרבית שנמדדה בחלון, לא ממוצע של שתי הדקות.

## במהלך המדידה

- אל תשנה מיקום, כיוון או מרווח דגימה.
- אל תלחץ HOLD בטעות.
- אל תיכנס לתפריטי איפוס או ניקוי.
- אם מחברים מקור מתח, הנח את הכבל והספק בצורה קבועה ותעד זאת, משום שהם חלק מסביבת המדידה.

## סיום הסשן

1. רשום את שעת הסיום בפועל.
2. אפשר להפעיל `HOLD` כדי לקבע נקודת עצירה מדויקת לפני העבודה בתפריטים.
3. היכנס ל־`Logger Setup`.
4. בחר `Save to FlashMem` והמתן לסיום הפעולה.
5. אל תלחץ `Clear buffer` בין סוף המדידה לבין `Save to FlashMem`.
6. כעת אפשר לכבות או לחבר למחשב לצורך ייצוא.

### מה עושה כל פריט

| פריט | תפקיד |
|---|---|
| `Logg time` | מרווח הזמן בין נקודות שמורות |
| `Clear buffer` | ניקוי הבאפר של המדידה הפעילה; להשתמש לפני סשן חדש בלבד |
| `Save` / `Save config` | שמירת הגדרות ה־Logger |
| `Save to FlashMem` | העתקת הסשן מהבאפר לזיכרון הלא־נדיף לפני כיבוי |
| `Read from FlashMem` | טעינת/קריאת התוכן שנשמר ב־FlashMem, לפי גרסת הקושחה |
| `Data2Send = RealTime` | בחירת נתונים חיים לשליחה |
| `Data2Send = FlashMem` | בחירת ההקלטה השמורה לשליחה |
| `Send data` | שידור המקור שנבחר דרך USB לתוכנת הטרמינל |
| `Reset` / `Reset config` | איפוס הגדרות; אינו שלב רגיל במדידה |
