# ייצוא עם Tera Term וטעינה לדשבורד

## א. מציאת יציאת ה־COM הנכונה

1. חבר את ה־Cornet בכבל Data.
2. פתח `Device Manager > Ports (COM & LPT)`.
3. רשום את מספר ה־COM שמופיע ליד ההתקן שנוסף.

אל תנחש COM3, COM5 או COM6 לפי צילום ישן. המספר הנכון הוא זה שמופיע עכשיו ב־Device Manager. אם תוכנה ממשיכה "למצוא" COM כשהמכשיר מנותק, זו אינה הוכחה לחיבור; ייתכן שהיא מציגה ערך שמור.

## ב. פתיחת Tera Term

1. סגור את תוכנת Monitoring וכל תוכנת Serial אחרת. רק תוכנה אחת יכולה בדרך כלל לפתוח את יציאת ה־COM.
2. פתח Tera Term.
3. בחלון New connection בחר `Serial` ואת ה־COM שמצאת.
4. פתח `Setup > Serial port` והגדר:

```text
Speed:        9600
Data:         8 bit
Parity:       none
Stop bits:    1 bit
Flow control: none
```

## ג. התחלת לכידה לקובץ

חשוב להתחיל את הלוג בתוכנה **לפני** הלחיצה על `Send data`, אחרת הנתונים יופיעו על המסך אך לא בהכרח יישמרו.

1. ב־Tera Term בחר `File > Log`.
2. צור שם קובץ שמתאר את הסשן, לדוגמה:

```text
2026-11-03_bedroom_2min_flash.csv
```

3. שמור בתיקייה פרטית מחוץ לריפו, או תחת `captures/` שמוחרגת מ־Git.

## ד. שליחת ההקלטה מה־Cornet

1. היכנס במכשיר ל־`Logger Setup`.
2. אם קיימת אפשרות `Read from FlashMem`, בחר בה והמתן לסיום.
3. קבע `Data2Send = FlashMem`, לא `RealTime`.
4. בחר `Send data`.
5. המתן עד שהשידור מסתיים וכל השורות מופיעות ב־Tera Term.
6. סגור את חלון הלוג או בחר `File > Close Log` כדי להבטיח שהקובץ נסגר ונכתב לדיסק.

שורת פתיחה אופיינית נראית כך:

```text
P0005,Interval=019,FlashMem
```

אחריה יופיעו שורות ערך ותדר. ערכים עם תדר `0000` הם תאים ריקים/סמנים והדשבורד מסנן אותם.

## ה. בדיקת הקובץ

פתח עותק ב־Notepad ובדוק:

- שיש יותר משורת כותרת אחת
- שיש שורות עם שני ערכים מופרדים בפסיק
- שהתדר אינו `0000` בכל השורות
- שמספר השורות הסביר ל־24 שעות במרווח 2 דקות הוא עד כ־720 קריאות תקינות

ה־FlashMem נשלח בדרך כלל מהקריאה החדשה לישנה. אין להפוך את הקובץ ידנית; הדשבורד עושה זאת בעת הטעינה.

## ו. טעינה לדשבורד

1. פתח את [הדשבורד החי](https://cornet-rf.167-233-222-219.sslip.io/) או את `dist/index.html`.
2. לחץ `טעינת קובץ Cornet` ובחר את קובץ ה־CSV/TXT.
3. בשדה `מרווח דגימה` הזן את המרווח בשניות:
   - 2 דקות = `120`
   - 3 דקות = `180`
4. ודא שמספר הקריאות והמשך המשוער הגיוניים.
5. אפשר ללחוץ `הורדת CSV` כדי לקבל קובץ מנוקה.

הקובץ נשאר במחשב ומעובד מקומית בדפדפן.

## ז. בניית זמן משוער

מכיוון שאין חותמות זמן בשורות, הדרך האמינה היא לשמור זמן התחלה וסיום בנפרד. אם ידועה שעת הסיום, אפשר לחשב לאחור:

```text
timestamp(i) = end_time - (number_of_samples - 1 - i) × interval
```

זהו זמן משוער בלבד אם היו HOLD, הפסקת מתח, שינוי מרווח או קריאות חסרות.

## תוכנת Monitoring הישנה

`Monitoring.exe` של EnviroSens יכולה להציג נתונים חיים, אך בבדיקה היא הציגה יציאות COM שמורות ואף נראתה כאילו מצאה מכשיר כשהוא נותק. לכן ההליך המתועד בפרויקט משתמש ב־Tera Term לייצוא גולמי. אין ללחוץ `Start Recording` בתוכנת Monitoring אם המטרה היא לייצא הקלטה שכבר נשמרה במכשיר.
