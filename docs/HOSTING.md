# פריסה ואחסון

הדשבורד הוא קובץ HTML סטטי ללא build וללא backend. אין צורך להעלות אליו קובצי מדידה; העיבוד מתבצע בצד הדפדפן.

## הרצה מקומית

אפשר לפתוח ישירות:

```text
dist/index.html
```

או להגיש את התיקייה דרך שרת סטטי לבחירתך.

## סביבת ה־Hetzner הנוכחית

- כתובת: [https://cornet-rf.167-233-222-219.sslip.io/](https://cornet-rf.167-233-222-219.sslip.io/)
- נתיב פעיל בשרת: `/srv/cornet-rf/current`
- Releases: `/srv/cornet-rf/releases/`

## עקרון פריסה

1. הרץ `node tools/validate-project.mjs`.
2. צור תיקיית release חדשה בשרת.
3. העלה אליה את תוכן `dist/`.
4. החלף את הקישור `current` רק לאחר שהקבצים הועלו בשלמותם.
5. אמת HTTP 200 ופתח את העמוד.

פרטי כניסה, מפתחות SSH וסודות אינם נשמרים בריפו. אין להוסיף אותם לקובצי תיעוד או ל־GitHub Actions.
